# MS Techniker — site web

Site vitrine de **MS Techniker**, startup de Mont Ngafula (Kinshasa) : systèmes embarqués, IA, énergie intelligente, IoT et offres serveurs.

## Contenu
- `index.html` : page unique (HTML, CSS et JavaScript intégrés, aucune dépendance à installer)
- `img/` : logos, photos des projets, de l'équipe et de l'atelier

## Sections
Accueil avec simulation 3D d'EFLOW V1 · Distinction Sixaxis (NASA Space Apps Challenge RDC 2025) · Domaines · Projets · Sites · Équipes · Offres serveurs · Atelier · Actualités · Contact

## Voir le site en local
Ouvrir `index.html` dans un navigateur.

## Publier avec GitHub Pages
Settings → Pages → Source : branche `main`, dossier `/ (root)`.
